## ✨ 产品简介

**DocGenius** 是一款基于 AI 技术的智能文档创作助手，专为需要**高效生成结构化内容**的用户而设计。

产品采用直观的**四步式工作流**——主题与大纲、内容规划、草稿撰写、最终定稿——引导用户从零开始，轻松完成一篇完整文档的创作。

用户只需输入想要写作的主题，并可选择设定文风与语气（如**幽默风趣、学术严谨或商务专业**），DocGenius 即可借助 **Google Gemini** 大语言模型自动生成内容大纲，并逐步细化为完整文章。

无论是**行业报告、学习指南，还是创意写作**，DocGenius 都能显著提升创作效率，帮助用户将灵感快速转化为高质量文档。

产品界面设计简洁大方，操作流程清晰，即便是没有写作经验的新手用户也能快速上手。DocGenius 是**内容创作者、学生、职场人士**的理想 AI 写作伙伴，让每个人都能轻松产出专业级文档内容。
